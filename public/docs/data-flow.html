    The status ladder an interview climbs

    what the ETL can filter on

    Every interview carries a status recording how far up the approval chain it has travelled. The ETL can filter on it — export_interview_status defaults to All, so the whole workspace is exported and the MIS decides what to keep.

    InterviewerAssigned→ Completed→ ApprovedBySupervisor→ ApprovedByHeadquarters
    RejectedBySupervisor RejectedByHeadquarters — back down for correction, then climb again
    Watch the enum names. The sent-to-HQ state is SentToCapi, not SentToCapital — and a wrong value raises no error: the filter is ignored and the whole set comes back.

    The merge: one row per person

    the step that used to be done in Excel

    Survey Solutions exports a household file and a separate member roster. The adapter joins them on the household code and writes one row per person — each member carrying its household's answers with it, so a person can be validated, scored and inserted on its own.

    Move 02 · The handoff

    What replaced what

    the spreadsheet step is gone

    Before

    • Someone exported from HQ by hand and carried the file.
    • Households and members were cleaned and reshaped in Excel.
    • The file was imported, then PMT was run as a separate step.
    • No record of who imported what, or when it last ran.

    Now

    • The MIS requests the export job itself and waits on it.
    • The adapter does the reshaping — the same way, every run.
    • PMT is computed inside the ETL, so an import lands already scored.
    • Every district import has a history row, a status and an owner.

      Summary

      Where this leaves us

      four things to remember
      One registry
      Survey Solutions and PSSN legacy each land in a defined store, and every downstream module — targeting, payroll, payment — reads the same records.
      Scored on arrival
      PMT is computed inside the ETL. An import lands ready for targeting, with no spreadsheet step and no separate scoring run.
      Measured, not assumed
      Timing, page sizes and statement counts on these slides come from dated runs against real districts — each one is traceable to a document.
      A loop that closes
      Paylists leave over GovESB and the return feedback reconciles payroll. Settled items close; failures stay open for the next cycle.
