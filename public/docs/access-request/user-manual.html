2. Apply for an Account (Applicant)

  1. On the TASAF MIS login page click Request Access, then Start application.
  2. Choose New user, or Activate existing if you had an account that is no longer active.
  3. Fill your details: full name, email (twice), phone (e.g. +255 712 345 678), section, job title, user category (TASAF Staff, PAA Staff, Other) and administrative level with its location. External applicants give their organization name.
  4. Press Submit application. Keep the reference code shown on screen.
Only one application per email can be in progress. If yours is already being processed, use its reference code to check the status.

3. Check the Application Status

Click Application status on the access page and enter the reference code exactly as it appears on the confirmation.

ShownMeaning

ApprovedYour account is ready; you receive your username and how to set your password.
Not approvedContact ICT support for details.

4. The Access Requests List

Open Administration → Access Requests. Filter by status, request type and user category; double-click a request to open it.

5. Approve or Reject a Request

Approvers act from the Tasks inbox or from the request page. The page has three tabs:

  • Overview: the applicant, request details, and Before you approve checks, e.g. Email already has an account (consider an activation instead), No account to activate, Missing fields.
  • Approvals: the approval chain. Each step unlocks the next; the header says which step is waiting.
  • History: every decision, in order.
  1. Read the checks on the Overview tab.
  2. Write a Decision note; it is required to reject and visible to the next approver.
  3. Press Approve or Reject.

6. Create or Activate the Account (ICT)

When both approvals are recorded the header reads ready to provision.

  1. Check the Username (at most 8 characters).
  2. Choose the Roles to assign. The same person should not hold both maker and approver roles.
  3. Check the Districts where the user may work; they are prefilled from the requested location.
  4. Press Create account (or Activate account).
  5. The Account ready window shows the username. If a temporary password is shown, it is shown only once: give it to the user privately and ask them to change it after first login (Profile → Change password). Otherwise the user sets the password from the emailed link.

7. Section Managers

On the Section managers tab of the Access Requests page, add the users who approve requests for each section. A section with no manager is signed by an administrator. A user listed without the Access Request Sponsor role cannot approve and is marked so.

9. Troubleshooting

ProblemWhat to do
“Too many attempts”Wait a minute and try again.
The reference code is not foundCheck it character by character.
No manager can approve a requestAdd a section manager, or an administrator signs.
Provisioning failedRead the error (often a username already in use), correct it and provision again.
